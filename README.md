# WallReinforcer

Плагин для Autodesk Revit, предназначенный для автоматизации армирования стен.

## Описание

**WallReinforcer** — это инструмент для автоматического создания арматурных стержней в стенах с учётом пересечений, выпусков и настроек защитного слоя. Плагин поддерживает работу с различными версиями Revit (2020–2025).

## Возможности

- Автоматическое армирование выбранных стен
- Учёт пересечений стен и колонн
- Создание вертикальных арматурных стержней
- Настройка защитного слоя арматуры
- Поддержка worksets в совместной работе
- Передача арматурных контейнеров и связанных элементов
- Гибкие настройки через конфигурационный файл

## Требования

- **Autodesk Revit**: 2020, 2021, 2022, 2023, 2024 или 2025
- **.NET Framework**: 4.7+ (для Revit 2020–2021), 4.8+ (для Revit 2022–2025)
- **WPF** (Windows Presentation Foundation)

## Установка

1. Склонируйте репозиторий:
   ```bash
   git clone <repository-url>
   ```

2. Откройте решение `Reinforcer.slnx` в Visual Studio.

3. Выберите нужную конфигурацию сборки в зависимости от вашей версии Revit:
   - `2020`, `2021`, `2022`, `2023`, `2024`, `2025` — для релизных сборок
   - `Debug 2020` – `Debug 2025` — для отладки

4. Соберите проект.

5. Скопируйте собранный DLL-файл в папку плагинов Revit:
   ```
   %APPDATA%\Autodesk\Revit\Addins\<Version>\
   ```


## Конфигурация

Настройки плагина хранятся в `App.config` и включают:

- Параметры арматурных контейнеров
- Типы и шаги арматуры
- Защитный слой бетона
- Настройки для пустот, колонн и балок
- Имена worksets для совместной работы

## Использование

1. Запустите Revit и откройте проект.
2. Выделите стены для армирования или выберите их после запуска команды.
3. Запустите команду **WallReinforcer** из панели инструментов.
4. Плагин автоматически создаст арматурные стержни согласно настройкам.

## Сборка

Для сборки проекта используйте MSBuild или Visual Studio:

```bash
# Пример сборки для Revit 2024
dotnet build WallReinforcer/WallReinforcer.csproj -c "2024"
```
